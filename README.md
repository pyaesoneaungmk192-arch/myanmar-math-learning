# Myanmar Math Learning (Flutter starter)

## လက်ရှိပါဝင်သောအရာများ
- မြန်မာဘာသာ UI
- မူလတန်း၊ အလယ်တန်း၊ အထက်တန်း၊ အဆင့်မြင့် အဆင့်ခွဲများ
- သင်ခန်းစာခေါင်းစဉ်များ
- အခြေခံ Quiz
- အခြေခံ Calculator

## သတိပြုရန်
ဤသည် offline starter/demo ဖြစ်သည်။ သင်ခန်းစာစာသားအပြည့်အစုံ၊ cloud database,
Admin Panel, account login, Live Chat နှင့် push notifications များ မပါဝင်သေးပါ။

## APK Build
Flutter SDK တပ်ဆင်ထားသော environment တွင်:
1. `flutter pub get`
2. `flutter build apk --release`
3. APK ကို `build/app/outputs/flutter-apk/app-release.apk` တွင် ရရှိမည်။
